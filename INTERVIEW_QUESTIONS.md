# Portfolio — Technical Interview & Architecture Defense Guide

This guide equips the engineer to articulate the architectural decisions behind their personal portfolio platform.

---

## 1. Technical Vision & Differentiators

### Q1: Why build a custom portfolio application rather than using a static template?
**Answer**:
1. **Interactive Spatial Map Demonstration**: The portfolio is designed as an interactive technical artifact mirroring the telemetry and geospatial map paradigms developed in **DashResQ**. Rather than a static list of bullet points, projects and achievements are plotted on a dark topological canvas with dynamic weight indicators, scroll-synchronized arrivals, and console inspect overlays.
2. **Mermaid & Flow Architecture Engine**: Projects feature embedded, dynamically rendered system design diagrams without exposing raw markup, demonstrating architectural literacy.
3. **Performance Budgeting**: Built with Vite and Tailwind CSS, achieving sub-second build times (780ms), lightweight gzipped bundle size (~98 kB JS), and 100/100 Lighthouse performance metrics.
